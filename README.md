# icon-theme-toolkit
An ambitious project for an integrated editing toolkit of Linux icon themes. Currently in Russian. [English beta-releases are here.](https://github.com/nestoris/icon-theme-toolkit_beta)

[RU] Амбициозный проект полноценного комбайна по редактированию темы значков на Linux. Разрабатывается на русском, но автоматически (иногда не полностью) переводится на английский.
