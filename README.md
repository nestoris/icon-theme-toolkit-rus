# Icon Theme Toolkit (Ящик с инструментами для темы значков)
An ambitious project for an integrated editing toolkit of Linux icon themes. Currently developed in Russian. [English version is here.](https://github.com/nestoris/icon-theme-toolkit)

[RU] Амбициозный проект полноценного комбайна по редактированию темы значков на Linux. Разрабатывается на русском, но автоматически (иногда не полностью) переводится на английский.
